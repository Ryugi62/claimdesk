# Technical demo script (≤ 3:00)

1. **The attack first (0:00–0:35)** — a forwarded link registers its own account before the real winner; the organizer clears for the address its paperwork was checked against → `RecipientMismatch` (mined); `reissueLink` → the old link's signature fails `BadClaimSignature` (mined) → the winner registers with the new link → paid; the forwardee got 0. Explorer links in the README proof table.
2. **Contract (0:35–1:10)** — `ClaimEscrow.sol`: award = token, amount, `party`, expiry, status in 2 storage slots (Tempo charges 250k gas per new slot; registration overwrites the link key with the account in the same slot). States Funded → Registered → Claimed (path A) or Funded → Cleared → Claimed (bearer); `revoke`/`reissueLink` only before clearance; `minTtl` floor; withholding split in `clear`. Signatures: EIP-191 over a domain tag (`claimdesk.register` / `claimdesk.claim`), escrow, chain, award, recipient; low-s only. `forge test`: 22 incl. a fuzzed conservation invariant with withholding.
3. **Tempo features (1:10–1:50)** — one Tempo transaction with batched calls funds every award (approve + N × fund). The winner's passkey (`Account.fromWebAuthnP256`) sends `register`; `withRelay` hands the transaction to our relay, which co-signs as fee payer only after `sponsorable()` (one register/claim call into our escrow, gas and fee caps, pinned fee token, no key authorizations), a simulation of the exact call, and per-IP/per-award limits — in a process that holds only the fee-payer key. Memos on every transfer; the account page pays its own fee in the stablecoin (no gas token).
4. **Organizer (1:50–2:30)** — console on localhost (organizer key; loopback + Host allow-list + session token): status rebuilt from events, "Clear & pay" dialog that shows the address and amount and requires a paperwork note (stored locally, salted hash on-chain, "Verify" re-derives it), batch clear in one transaction, reissue, revoke, mail-merge export.
5. **Winner (2:30–3:00)** — phone width: link → passkey → "Account ready" (registered tx) → cleared → receipt in won + PDF → send with an exchange deposit tag.
