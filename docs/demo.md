# Technical demo script (≤ 3:00)

1. **Contract (0:00–0:40)** — `ClaimEscrow.sol`: award = token, amount, claim-key address, expiry, status (+ recipient when registered); id = 32-byte memo, 2 slots (Tempo charges 250k gas per new slot). `register` (claim key signs `claimdesk.register` + escrow + chain + id + recipient) · `clear` pays a registered account in the same call, else opens `claim` · `revoke` only before clearance · `rotateSigner` · `reclaim` after expiry · two-step organizer. `forge test`: 27 pass incl. a fuzzed conservation invariant.
2. **Organizer (0:40–1:10)** — CLI `deploy` (organizer key + separate fee-payer key) → `batch` funds every award in ONE Tempo transaction with batched calls (approve + N × fund) → console at localhost: status rebuilt from events, Clear / Revoke buttons, mail-merge export.
3. **Winner (1:10–2:05)** — phone width: link → "Create my account" → WebAuthn passkey (`Account.fromWebAuthnP256`) → `register` sent through `withRelay`; our relay co-signs as fee payer only after `sponsorable()` (one register/claim call into our escrow, gas cap, no key authorizations) and a simulation, rate-limited per IP → organizer clears → receipt with KRW at the ECB rate + PDF → account page sends with a deposit tag, fee token = the stablecoin.
4. **Chain proof (2:05–2:40)** — explorer: register tx (WebAuthn signature + fee-payer signature), clear tx with the `TransferWithMemo` to the registered account, and five mined refusals with their custom errors.
5. **Choices (2:40–3:00)** — memo = id · claim key only in the URL fragment · register-before-clear binds compliance to the paid account · pure domain (tested: no SDK imports) · static build of the winner pages uses Tempo's public testnet sponsor.
